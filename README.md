# CyberWatch Chrome Extension

This is a Chrome extension that helps you spot phishing attempts and scams while you browse. It brings the scam detection directly into your browser so you don't have to leave the page to check if something is suspicious.

## Why I Built This

Scams are getting smarter every day. Most people can't tell the difference between a legitimate message and a phishing attempt anymore. I wanted to make it easy for anyone to analyze suspicious links and messages right from their browser without needing to be a tech expert.

## What It Does

* Scan links directly from any webpage
* Check text and messages for scam patterns
* Get instant feedback on whether something looks suspicious
* Simple popup interface in your Chrome toolbar
* Clear explanations so you understand why something might be dangerous
* Works seamlessly without slowing down your browser

## How to Use It

1. Click the CyberWatch icon in your Chrome toolbar
2. Paste a link or text you want to check
3. Get instant analysis and recommendations
4. Right click on any link to scan it quickly

## Built With

* JavaScript for the extension logic
* HTML and CSS for the interface
* Chrome Extensions API for browser integration
* Connected to the CyberWatch AI backend for intelligent analysis

## Try It Out

Visit cyberwatchai.com to see the full platform and get the extension.

## About This Project

This extension is the browser interface for CyberWatch AI. The actual scam detection happens on the backend which is handled by the main CyberWatch platform. This repository contains just the extension code that makes it accessible from your browser.
