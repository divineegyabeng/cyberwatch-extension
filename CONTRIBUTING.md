# Contributing to CyberWatch Chrome Extension

Thank you for your interest in contributing to the CyberWatch Chrome Extension! This guide will help you get started.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/cyberwatch-extension.git`
3. Create a new branch: `git checkout -b feature/your-feature-name`
4. Make your changes
5. Commit your changes: `git commit -m "Add your commit message"`
6. Push to your fork: `git push origin feature/your-feature-name`
7. Open a Pull Request

## Setting Up Your Development Environment

1. Install Node.js (if needed)
2. Install dependencies: `npm install`
3. Load the extension in Chrome:
   - Go to `chrome://extensions/`
   - Enable "Developer mode"
   - Click "Load unpacked"
   - Select the extension folder

## Code Style

- Use clear, descriptive variable names
- Add comments for complex logic
- Follow the existing code style in the repository
- Test your changes in Chrome before submitting

## Testing

- Test the extension in different scenarios
- Check for console errors in Chrome DevTools
- Test with various types of suspicious links and messages

## Reporting Issues

Found a bug? Have a suggestion? Please open an issue with:

- A clear description of the issue
- Steps to reproduce (if it's a bug)
- Expected vs actual behavior
- Screenshots if applicable

## Pull Request Process

1. Ensure your code follows the project's style guidelines
2. Update the README if your changes affect documentation
3. Add a clear description of your changes
4. Test thoroughly in Chrome
5. Be open to feedback and willing to make changes

## Questions?

Feel free to reach out by opening an issue or contacting the maintainer.

Thank you for contributing!
